# **Интернет-магазина**

## Интернет-магазина

Веб-приложение интернет-магазина, построенное на фреймворке Django.
Проект реализует полный цикл работы с товарами, категориями, блогом и пользователями
с использованием современных подходов: кастомная модель пользователя,
система прав доступа, группы, кэширование через Redis и строгая типизация кода.

---

## Нововведения и функции

### Нововведения для пользователей

- **Регистрация и вход** — регистрация по email с подтверждением пароля,
  автоматическая отправка приветственного письма через Gmail SMTP.
- **Личный кабинет** — просмотр и редактирование профиля (email, имя, фамилия,
  аватар, телефон, страна).
- **Каталог товаров** — просмотр списка товаров, детальные страницы,
  фильтрация по категориям.
- **Создание товаров** — авторизованные пользователи могут добавлять свои товары
  (автоматически привязываются к владельцу).
- **Блог** — публичный раздел с публикациями, доступный всем посетителям.
- **Контактная форма** — отправка сообщений с обработкой POST-запросов.
- **Пагинация** — удобная навигация по спискам товаров и публикаций.

### Нововведения технические (не предназначенные для глаз пользователя)

- **Кастомная модель пользователя** (`CustomUser`) — наследуется от `AbstractUser`,
  email используется как `USERNAME_FIELD`.
- **Система прав и групп**:
  - Группа **«Модератор продуктов»** — может отменять публикацию и удалять любые товары.
  - Группа **«Контент-менеджер»** — полное управление публикациями в блоге.
  - Группа **«Пользователи»** — базовые права на просмотр и добавление товаров.
- **Владелец товара** (`owner`) — автоматическая привязка товара к авторизованному
  пользователю при создании.
- **Статус публикации** (`is_published`) — товары по умолчанию создаются как черновики.
- **Защита эндпоинтов** — `OwnerOrModeratorMixin` проверяет, что редактировать/удалять
  товар может только его владелец или модератор.
- **Кастомные команды Django**:
  - `create_moderator_group` — создание группы модераторов с нужными правами.
  - `create_content_manager_group` — создание группы контент-менеджеров.
  - `create_users_group` — создание базовой группы пользователей.
  - `createadmin` — создание суперпользователя с проверкой существования.
- **Кэширование через Redis**:
  - Кэширование страницы детального просмотра товара (`cache_page`).
  - Низкоуровневое кэширование списка товаров категории с ключом `category_{id}` и TTL.
  - Сервисный слой `catalog/services.py` для работы с кэшем.
- **Строгая типизация** — все файлы проходят проверку `mypy` без ошибок.
- **Линтеры и форматирование** — `black`, `isort`, `flake8` настроены с длиной строки 119.
- **Тестирование** — `pytest` с измерением покрытия кода через `pytest-cov`.
- **Работа с данными** — `pandas`, `openpyxl` для Excel, `requests` для API,
  `schedule` для автоматических задач.

*Дальнейшие функции будут описаны в последующих обновлениях.*

## Инструкция по настройке линтеров для данного проекта

Создайте файл с названием `.flake8` и в нём введите следующие настройки:
```ini
[flake8]
max-line-length = 119
ignore = E402, E251, E203
exclude = .git, .venv, __pycache__, venv
```
Вводите в файл pyproject.toml, если там не прописано, то пропишите следующие.
```
[tool.black]
# Максимальная длина строки
line-length = 119
# Файлы, которые не нужно форматировать
exclude = '''
(
  /(
      \.eggs         # Исключить несколько общих каталогов
    | \.git          # в корне проекта
    | \.hg
    | \.mypy_cache
    | \.tox
    | \.venv
    | dist
  )/
  | foo.py           # Также отдельно исключить файл с именем foo.py
                     # в корне проекта
)
'''


[tool.isort]
# максимальная длина строки
line_length = 119


[tool.mypy]
disallow_untyped_defs = true
warn_return_any = true
ignore_missing_imports = true
[tool.django-stubs]
django_settings_module = "config.settings"
exclude = "venv"

```
И все зависимости что есть на данный момент будут прописаны.
